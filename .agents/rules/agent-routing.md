## Ambiguity & Escalation
- **Active Live Recording**: Speaker hints (`Speaker - "..."`, `Speaker "..."`, quote attributions) route strictly to Route 0c (Silent Speaker Hint, ZERO conversational chat replies). Every other prompt or question during an active recording defaults strictly to Route 0b (Live Copilot using live transcript and graph cache), UNLESS explicitly prefixed with `"query"` (which ignores the live transcript and performs deep GraphDB traversal via Route 2). When no recording is active, route questions to Route 2 or 6.
- **Entity-Anchored & Imperative Synthesis Queries (`INV-QUERY-ENTITY-ADVISORY-TRAVERSAL`)**: Requests for executive agendas, talking points, stakeholder prep, or workstream summaries containing named entities route strictly to Route 2 (Query) and Route 6 (Decision Intelligence), taking precedence over conversational style rules and requiring live GraphDB traversal against canonical tables before emitting delivery payloads. Formatting constraints (e.g. `< 50 words`, bullet counts, executive style) are delivery boundary parameters, NEVER grounds for bypassing GraphDB traversal in favor of hallucination or prompt-echoing.
- **Temporal Existence & Deliverable Aliases (`INV-QUERY-TEMPORAL-SOURCE-EXISTENCE` / `INV-QUERY-DELIVERABLE-ALIAS-BINDING`)**: Queries for a specific date/time meeting (`today`, `3:30 PM ET`) must verify `source.source_date` in `graph.sqlite` via `verify_temporal_source_existence()`. If missing, state **"Not in Knowledge Graph"** and check `.local/dual_pipeline/dlq/` + `.worktrees/`; never silently substitute older meetings. Bind `"output(s) 1/2/3"` strictly to synthesis deliverables `01_*`, `02_*`, `03_*`.
- **Ingestion Failures & Retries**: Strictly prohibit manual hand-editing of `01_*` or `02_*` deliverables or running ad-hoc python scripts following attribution or gate failures. Allow at most 2 automated remediation cycles within 600s SLA; upon failure or resume, execute via governed CLI: `.venv/bin/python nee.py ingest-meeting --resume --input <source_file>` to reuse cached stages.
- Source material + question -> Ingestion priority. Governance + other -> Governance priority.
- Graph mutation without approval -> Stop and request approval.

## Execution Environment & Default Model Routing Invariant
- **Antigravity IDE Default**: Unless operator explicitly specifies an approved external model, agent execution, planning, tools, and tests MUST run within **Antigravity IDE**.
- **Provider Boundary**: Autonomous execution defaults to hermetic local environment; external calls never invoked implicitly.
